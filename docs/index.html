node-ptero

A Node.js 24.15.0 Docker image for Pterodactyl and Pelican. A drop-in replacement for the official Pelican Node.js image, so the generic Node.js egg works without changes.

Use it in your panel

Import the generic Node.js egg, then add this image to it.

  1. Download the egg: egg-nodejs-generic.yaml
  2. In the admin panel, go to Eggs → Import and upload it.
  3. Open the egg, find Docker Images and add a new entry: 
    Name:  Nodejs 24.15.0
Image: ghcr.io/project-phil/node-ptero:24.15.0
  4. On your server, go to Startup and select Nodejs 24.15.0.
  1. Download the egg: egg-pterodactyl-nodejs-generic.json
  2. In the admin panel, go to Nests, pick a nest and click Import Egg.
  3. Open the egg and add this line to Docker Images: 
    Nodejs 24.15.0|ghcr.io/project-phil/node-ptero:24.15.0
  4. On your server, go to Startup and select Nodejs 24.15.0.
The egg's startup command runs as normal. Variables like {{SERVER_PORT}} are filled in, and INTERNAL_IP is set for your app.

Build it yourself

With GitHub Actions

Fork the repo. The included workflow builds for x64 and arm64 and pushes to ghcr.io/<you>/node-ptero whenever the Dockerfile changes, or when you run it from the Actions tab. No secrets needed.

With Docker

git clone https://github.com/Project-Phil/node-ptero.git
cd node-ptero
docker login ghcr.io -u <YOUR_GITHUB_USERNAME>
docker buildx create --use
docker buildx build --platform linux/amd64,linux/arm64 \
  -t ghcr.io/<your-username-lowercase>/node-ptero:24.15.0 --push .

Image names on ghcr.io must be lowercase.

Changing the Node.js version

Change the tag on the FROM line in the Dockerfile (for example node:24.16.0-trixie-slim) and the version label. The workflow tags the image with that version automatically.
